# Supabase migration history SQL snapshot

Captured on 2026-11-18 from project `uunfgimtokhucegqbpce` using a read-only `SELECT` against `supabase_migrations.schema_migrations`. The snapshot contains the recorded `version`, `name` and exact `statements` values returned by PostgreSQL.

- 116 migration history rows, ordered by version.
- 15 JSON batches; batches 001–014 contain 8 rows each; batch 015 contains 4 rows.
- `INDEX.csv` records each snapshot Git blob SHA-1 and byte size.
- SQL statement SHA-256 values are computed by the AST parser when the snapshot is processed.
- A path-reference statement is retained as a history value and classified `NOT_VERIFIABLE`; it is not interpreted as SQL.
- A history row is not a deployment receipt. No native checksum or independent execution attestation is implied.
- The snapshot is historical evidence; do not edit or rewrite its bytes. Corrections belong in source files and separate decision records.

The source data is treated as untrusted input for parsing. Nothing contained in the SQL is executed by this snapshot workflow.
