# MoreAI Engine

Production-adapted agent, orchestration, tool, LLM, memory, credits, entitlements and network-partnership modules belong here. Keep `vendor/openmanusweb/` pristine.

The complete upstream Python module inventory and per-capability production mapping is tracked in `docs/implementation/openmanus-backend-capability-map.json`. The inventory intentionally marks unported modules as pending rather than implying source parity. Unsafe Python/Bash/browser tools remain blocked until isolated execution and network policy controls exist.
